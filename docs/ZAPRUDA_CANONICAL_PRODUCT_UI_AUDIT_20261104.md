## 1. Продукт
**ZAPRUDA COMMUNITY — единая рыболовная экосистема для всех направлений рыбалки, а не только для спиннингистов.** Отдельные взаимосвязанные модули, один профиль, репутация и безопасные данные:
- **COMMUNITY:** лента, отчёты, подписки, клубы, гео/тематические чаты, бесплатные СХОДКИ.
- **FISHING MAP / SPOT:** водоёмы, опубликованные проверенные споты, карта, закрытые точные GPS.
- **ZAPRUDA STREET:** личные городские рыболовные сессии (таймер, примерный район, журнал уловов, необязательный перенос в отчёт). Не равно соревнованию.
- **ZARUBA:** соревнования/батлы на подтверждённых SPOT, BIG FISH одной рыбы, отдельно номинации и дисциплины.
- **TROPHY SYSTEM:** подтверждённые достижения, титулы, история смены KING, строгая модерация.
- **SPOT MARKET:** карты/авторы/покупки — отдельный будущий этап; не выдавать за текущий платежный релиз.
- **AI FISHING:** правило-базовый план рыбалки и отдельное усиление AI, провайдеры/квоты требуют live acceptance.
- **Общая платформа:** единый профиль и права, уведомления, приватность, модерация, оплаты только после релизного решения.

## 2. Последние подтверждённые UI/UX решения (ветка беседы «Проверка палитры Electric Blue», 03.11.2026)
- **Matte Black** — оформление по умолчанию; тёмно-графитовая база, лайм и существующие подходящие вторичные акценты; не ломать при доработке второй темы.
- **Electric Blue** — добровольная настройка фона, должна сохраняться после обновления/повторного входа в том же браузере. В этой теме **НИ ОДНОЙ** тёмно-зелёной/оливковой поверхности и старого сиреневого акцента: **синий + электролайм + баклажановый**. Ориентиры: blue #1239A6, lime #D7FF35, eggplant #614051; проверять реальную читаемость и computed styles, не путать с Matte Black. Исправление карточек, шапки, нижней навигации и превью чата отражено в истории PR #63/#82; это НЕ доказательство соответствия текущего Netlify.
- **Премиальная доработка** интерфейса без нового глобального навбара: мобильная читаемость, иерархия карточек, меньше длинных инструкций/избыточных hero-блоков, быстрые состояния, качественная фотография и фирменные элементы. Функциональная короткая анимация, с учётом reduced-motion.
- **Порядок работы:** чаты → отчёты → мобильный UX → SPOT; foundations параллельно.
- **Отчёт — три шага с автосохранением:** `Где и когда` → `Улов и история` → `Проверка и публикация`. Должны оставаться черновик, приватность, отсутствие улова, повтор без дубля; фото после reload нужно прикрепить заново. Это согласованный UX, но не засвидетельствован как завершённый.
- **Меню:** Лента · Комьюнити · + · Выезды · Чат (всегда пять публичных вкладок); остальные модули внутри маршрутов/разделов, административное — только ролям.
- **Видимые данные:** никакой фиктивной ленты, рекордов, онлайна, числа непрочитанных, рыбы или отзывов.

## 3. STREET / SPOT / ЗАРУБА / титулы — НЕ смешивать
```text
ЛИЧНАЯ STREET-СЕССИЯ
таймер → заметки/уловы → закончить → [по желанию] отчёт
             │ НЕ присваивает титул
             ▼
ПОДТВЕРЖДЁННЫЙ SPOT / ZARUBA
дисциплина → спот/водоём → номинация → фото-доказательство → проверка модератором
                                                ▼
                                          VERIFIED CATCH
                                                ▼
                      рейтинг / история KING / адресное уведомление
```
Канонические категории в действующей owner-approved UX-спецификации и `src/lib/spot-records.ts`:
| Направление | Номинация | Титул | Правило |
| --- | --- | --- | --- |
| STREET | spot-big-fish | **KING OF THE SPOT** | одна крупнейшая подтверждённая рыба по массе на споте |
| STREET | spot-longest | **LENGTH KING** | подтверждённая длина |
| UL/MICROJIG | ul-big-fish | **KING OF UL** | масса с проверкой снасти |
| UL/MICROJIG | ul-smallest | **MICRO KING** | минимальная допустимо подтверждённая длина, с этической проверкой; внутри UL |
| CARPFISHING | carp-big-fish | **KING OF THE LAKE** | карп/амур по водоёму |
| WINTER | ice-big-fish | **KING OF THE ICE** | регион/сезон/метод/вид; без обязательного точного спота |
| BOAT | boat-big-fish | **TROPHY KING** | вид рыбы, водоём/регион/масштаб |
Титул меняется только после реальной проверки независимым уполномоченным модератором; равенство результата не выбивает KING. Публикация безопасной карточки — с согласия автора. Смена KING уведомляет владельца/предыдущего лидера/подписчиков соответствующего спота согласно настройкам; не рассылать на всю страну. Трофейные поздравления (например, «ЛЮТЫЙ СУДАК!») только после подтверждения и согласования порогов; численные пороги в спецификации остаются **DRAFT**.

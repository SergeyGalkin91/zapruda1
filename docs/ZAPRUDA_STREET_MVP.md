# ZAPRUDA STREET — MVP и направление развития

## Продукт
Urban / Street Fishing — самостоятельный раздел внутри ZAPRUDA COMMUNITY, маршрут `/street`. Использовать визуальный язык утверждённых мобильных референсов; не менять пятиэлементную нижнюю навигацию. Точка входа — карточка на главной, дополнительно возможно меню «Комьюнити».

## Реализовано (MVP 2026-10-31)
- Городская Street-сессия: начало, необязательный район, таймер по времени начала, список уловов с примечанием, завершение.
- Сохранение одной текущей/завершённой сессии в localStorage данного браузера; без авторизации и без SQL.
- Никаких GPS/публичных координат и автоматических фото/EXIF.
- Переходы к существующим `/reports/new`, `/partners`, `/chat` (тема «Споты и вода»).
- Результат Street-сессии пока не переносится автоматически в публичный отчёт. Не представлять локальный дневник как облачную синхронизацию.

## Следующие этапы (ещё НЕ реализованы)
1. Безопасный перенос данных завершённой сессии в существующую форму отчёта, без дублирования сущностей и с согласия пользователя.
2. Подключение Waterbody ID с учётом существующей схемы и приватности точных координат; проверка перед миграцией.
3. Лента и городские подборки Street без фальшивой активности.
4. Street Crew через существующие выезды и сообщества.
5. Street Challenges, добровольные турниры, модерация, антинакрутка; после завершения основных сценариев.

## Параллельный приоритет
**НЕ прекращать работу над «СВОИ НА СВЯЗИ».** Утверждённые файлы: `ГЛАВНОЕ МЕНЮ ДИЗАЙН.png`, `ОСНОВА приложения.png`, `Дизайн входа.pdf`. Чат — список шести комнат, отдельно переписка, не придумывать реальные данные. Утверждённый интерфейс важнее косметических альтернатив.

## Ограничения
Не использовать Canva. Не расходовать Lovable AI-кредиты на правки кода. Выполнять код в GitHub, проверять CI, публиковать только проверенные сборки. Не добавлять новые таблицы без анализа существующих. Не заявлять о проверке на реальном телефоне без её выполнения.

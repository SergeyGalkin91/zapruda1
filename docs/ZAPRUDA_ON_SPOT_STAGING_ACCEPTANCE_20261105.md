## Условия разблокировки

1. Восстановить одноразовое подтверждение Supabase для применения `v076_on_spot_social_privacy` к `yudtbifopfnjtjanaqrd`. Интеграция возвращает просроченный запрос. После применения сверить журнал и ACL, затем развернуть обновлённый `report-photo-access` в том же проекте.
2. Разрешить только точную ветку `work/v076-on-spot-plus-stage1-20261105` в `staging-e2e`, сохранив Required reviewers и остальные правила. Для положительного теста предоставить законный проверенный SPOT и одобренную зону. Её идентификатор задаётся в переменной окружения `ZAPRUDA_OSP_E2E_ZONE_ID`. После этого запустить защищённый workflow и дать владельцу ссылку на конкретный review. [Настройка среды](https://github.com/SergeyGalkin91/zapruda1/settings/environments/26071564803/edit)
3. Для проверки KING определить разрешённого независимого модератора, проверенный SPOT нужной дисциплины и подлинный улов с доказательствами. Для проверки списка рыбаков нужен пятый согласившийся подтверждённый участник.
4. Войти в существующую команду Netlify с доступом к STAGING, создать Deploy Preview из PR #114 и сверить `COMMIT_REF`, публичную конфигурацию STAGING и открытие страницы на мобильном. [Панель Netlify](https://app.netlify.com/)

# ZAPRUDA — добровольный обмен спотами и клубные выезды (план, не реализация)

Статус: будущая функция, отдельная ветка. Зафиксировано 2026-11-02.

## Принцип приватности
- Точные координаты личных спотов закрыты по умолчанию.
- Владелец может **явно** поделиться точкой через отдельную кнопку **«Поделиться спотом»** в чате ZAPRUDA SPOT либо в созданном им клубе/комьюнити.
- Никакой автоматической публикации спотов при создании отчёта или записи на выезд.
- Перед отправкой явно показать аудиторию: личный чат / выбранные участники / клуб / публичное сообщество, и точность: точная точка либо приблизительный район. Точность и аудитория не должны подразумеваться по умолчанию.
- Для приватной группы доступ виден только участникам, однако получатель может вручную сохранить или переслать координаты — предупреждать до отправки.
- Автор может отменить доступ в приложении; это не удаляет уже сделанные скриншоты/копии.

## Сообщества и мероприятия — последующие задачи
- Пользователь создаёт клуб/комьюнити и управляет участниками/ролями.
- Объявление выезда, например городской стрит-фишинг: дата, место сбора, лимит людей, участники, комментарии.
- Соревнования в будущем: регистрация, правила, статусы, результаты и модерация.
- Событие может ссылаться на опубликованный по согласию спот, но не раскрывает другие личные метки автора.

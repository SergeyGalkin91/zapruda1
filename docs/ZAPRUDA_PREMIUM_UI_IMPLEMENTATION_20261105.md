## Внедрено

- Общий компактный белый wordmark/лаймовая рыбка, нейтральные графитовые поверхности, #D7FF35 / #F2F2F2 / #0B0D0E / #1A1D21. Electric Blue сохранена отдельно.
- Реальный `/welcome` с брендом и работающими переходами, доступен из меню; существующие маршруты не переназначены.
- Лента: компактная иерархия и переходы, карточки настоящих отчётов/реакции/фотогалерея сохранены, empty/loading/error и retry. Нет выдуманных публикаций.
- Сообщества: поиск по реальной географии каталога, выбор страны, реальные переходы в чат/Атлас, клубы/СХОДКИ/гиды/Telegram/feedback сохранены. Участники и счётчики из концепта не подставляются.
- SPOT: бренд, реальная карта провайдера, выбор одобренной карточки; при пустом каталоге карта без маркеров и честный empty state. Кандидаты не выдаются за проверенные споты. Турниры, лидерборды и весь CatchFlow сохранены.
- Профиль: брендированная обложка, настоящая серверная статистика вместо демонстрационных чисел, быстрые переходы к снастям/достижениям/настройкам, существующее редактирование/аккаунт/приватные разделы сохранены.
- Настройки: независимая ось обоев Matte Black / Carbon / Neon Threads / Topographic. Локальные векторы/CSS без сетевых обоев и постоянной анимации, reduced-motion, сохранение v1 настроек и выборов после reload. Allowlisted pre-paint bootstrap предотвращает вспышку другой темы.
- Нижнее меню остаётся Лента / Комьюнити / + / Выезды / Чат. Оформление остальных модулей не объявляется завершённым.

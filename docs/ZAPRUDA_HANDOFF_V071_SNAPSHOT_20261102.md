## Действующие решения владельца
- Текущая рабочая основа — `release/v0.7.0-alpha`. Следующая версия по плану — **v0.7.1**.
- **СХОДКИ — MUST HAVE v0.7.1.** Локальные объявления: страна → регион → город. Принятый отклик создаёт приватную СХОДКУ; максимум **3 человека включая организатора**; точные место/время обсуждают только принятые участники. Не путать с клубами (500 ₽ / 15 человек) и гидами (10% платных услуг).

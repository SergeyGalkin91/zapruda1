## Фактические browser assertions (PASS)
- Matte Black `classic` остаётся темой по умолчанию; исходный CSS-токен `--z-violet` по-прежнему `#B4A1D7`, фирменный лайм `#D7FF35` не меняется.
- Electric Blue выбирается по кнопке на `/settings`; CSS `--background:#1239A6`, `--primary:#D7FF35`, `--z-violet:#614051`; применяется синий градиент `#1458DB -> #1239A6 -> #091D57`.
- Тема сохраняется после `reload` и при переходах на `/`, `/communities`, `/partners`, `/chat`, `/profile`. После возвращения к Matte Black и reload она остаётся чёрной.
- На обеих ширинах у проверенных маршрутов нет горизонтального overflow, корневого экранa ошибки и необработанных browser pageerror.
- Контраст WCAG formula для ключевых сочетаний (нормальный текст ≥4.5:1): лайм на самом ярком синем **5.29:1**, лайм на базовом синем **8.44:1**, светлый текст на баклажановом **7.78:1**. Текст цвета eggplant непосредственно на синем не используется (контраст около **1.09:1**).
- Скриншоты главных экранов и настроек сняты **по двум реальным областям viewport: верх и после прокрутки**. У Chromium `fullPage=true` с fixed gradient даёт ложные белые полосы после первого viewport; проверка с `fullPage=false` и прокруткой подтвердила корректный синий фон. Это особенность скриншотного захвата, не UI bug.

## Ограничения — перед release остаются
- Это **не физический iOS/Android**, не Safari и не реальные учётные записи. Требуются тесты на реальных мобильных устройствах/браузерах и проверка логина/логаута.
- Проверено сохранение в `localStorage` **на одном браузере**. Кросс-девайс синхронизация через Supabase **не реализована**, политика аккаунт-уровня не проверена.
- Большинство существующих карточек/хедера остаются тёмными по утверждённому design lock — пользователь меняет **фон**, не всю цветовую схему компонентов.
- Это автоматические проверки + просмотр нескольких скриншотов; **полной аудит-системы контраста всех текстовых узлов и всех состояний (errors, disabled, dialogs) нет**.
- Ревью с владельцем и окончательное согласование цветов/UX перед объединением PR.

**Решение:** считать браузерную геометрию и базовый контраст пройденными, но PR оставить **draft**. Не сливать, не деплоить и не утверждать релиз без приёмки.

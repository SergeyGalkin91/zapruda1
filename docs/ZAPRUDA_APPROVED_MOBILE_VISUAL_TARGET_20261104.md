## Исходный выбранный визуальный макет
Пять мобильных экранов на одном презентационном листе ZAPRUDA COMMUNITY (генеративный концепт в проектном чате):
1. Splash — чёрный карбон, мягкие тонкие лаймовые нити, минималистичная контурная рыба над ZAPRUDA COMMUNITY, фотография рыболова в сумерках.
2. Feed — компактная шапка с фирменной рыбой/словом ZAPRUDA, рыболовные фотографии, интерактивные карточки, лаймовые состояния, нижняя навигация.
3. Сообщества — компактный каталог регионов и сообщества; карточки с фотографиями/названиями, фильтры и чёткие CTA.
4. SPOT — минималистичная тёмная карта, лаймовые маркеры, карточка спота и информация об условиях.
5. Профиль — аватар, статистика, снасти, достижения и редактирование в чёрно-графитовой палитре.

**Договорённость о визуале:** премиальный вариант Б (разреженный наклонный geometric uppercase), контурная тонкая лаймовая рыбка, минималистичные фирменные wordmarks; Carbon/Topographic/Neon Threads — настраиваемые тихие обои, без пересветов/резких переходов, Matte Black default, Electric Blue alternate. Детали [бренд-спецификации](ZAPRUDA_BRAND_IDENTITY_APPROVED_20261104.md) и [истории референсов](ZAPRUDA_BRAND_IDENTITY_ARCHIVE_INDEX_20261104.md) обязательны.

## Важное разделение источников
- **Утверждено:** художественное направление, пропорции/ощущение UI и структура экранов как референс.
- **Не утверждено как реальные данные:** имя профиля, фотографии, числа подписчиков/сообществ, уловы, температура/погодные сведения, карты/споты — генерировались для визуализации. Данные демонстрации не копировать в БД и не подменять реальные.
- **Продуктовая навигация по контракту:** Лента / Комьюнити / + / Выезды / Чат; на презентационном листе нарисованное меню может отличаться. Сохранить действующий contract, без вычеркивания функциональности.
- **Названия модулей:** STREET, SPOT и весь набор функций/56 IDs/8 модулей/7 KING titles остаются по CURRENT_PRODUCT_SPEC.
- **Не использовать сгенерированный лист как production asset:** финальные векторные рыбка/wordmark, иконки 1024+adaptive, фото с правами использования; настоящий UX и accessibility.

## Два разных условия готовности
**PHONE VISUAL PREVIEW**: пользователь может открыть staging-only URL на своём смартфоне, увидеть новый UI (splash/feed/communities/SPOT/profile), на 320/390 px нет наложений, меню работает и сохраняется тема, нет production requests. Релизные KING gates не обязаны быть закрыты для изолированного визуального прототипа.

**FUNCTIONAL PHONE ACCEPTANCE**: все задействованные функции этих страниц работают с настоящими STAGING JWT, с проверкой ошибок/empty/loading/network, реальные данные без mock, тестирование чата, отчёта, STREET, SPOT, основных routes на телефоне/эмуляторе, сохранение выбранных обоев и accessibility. Требует отдельного Playwright/hosted QA, owner approval для merge.

**RELEASE GO**: другие самостоятельные P0 gates, в том числе KING, protected JWT, production readiness; не смешивать с проверкой дизайна.

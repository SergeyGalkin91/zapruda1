# ZAPRUDA — утверждённое направление фирменной айдентики
**Решение владельца: 04.11.2026. Статус: APPROVED — visual direction.**
**Не путать с:** готовым векторным мастер-файлом, утверждённым экраном приложения, кодом, релизным GO или разрешением менять main/production.

## 1. Что утверждено

Владелец после серии сравнительных эскизов прямо сказал: **«утверди эту айдентику»**. Утверждается **последнее показанное семейство ZAPRUDA**:
- Основной шрифтовой логотип — **вариант Б, лаконичный премиальный**: светлый белый/почти белый наклонный геометрический uppercase `ZAPRUDA`, удлинённые пропорции, аккуратное расширенное межбуквенное расстояние; гармония тонкого и толстого штриха, без массивного спортивного гротеска. На бренд-презентации лаймовая тонкая линия — возможный малозаметный акцент, не обязательная «светящаяся полоса» на каждом экране.
- Вторичные локапы: **ZAPRUDA COMMUNITY**, **ZAPRUDA SPOT** — единое начертание ZAPRUDA и сдержанные небольшие разреженные подписи COMMUNITY/SPOT. Лаймовый акцент на SPOT допустим в Matte Black, подбирать альтернативу для Electric Blue по утверждённой палитре темы.
- Фирменная рыба: **небольшой минималистичный контур одной рыбы** — отсылка к ранее согласованной ранней эмблеме/круглой рыбке, но переработанная под геометрию варианта Б: тонкая ровная непрерывная/сознательно разорванная линия, острые чистые концы, один глаз/жаберный штрих по необходимости. Без натуралистичной детализации, крючков, теней и громоздкой рамки. По цветовому акценту — Electric Lime на Matte Black. В лого может идти справа от ZAPRUDA, отдельно над названием или компактно в иконке.
- Иконка приложения: **рыбка + читаемая надпись ZAPRUDA** на тёмной лаконичной квадратной/скруглённой подложке для App Store/Android. Исходные просмотренные концепты №01, №05, №11, №20 — **референсы**, не утверждённые производственные файлы: контурная светящаяся окантовка (01), спокойная топография (05, 11), чёрный карбон с диагональной структурой (20). Не использовать прежнюю тяжёлую Z-эмблему с рыбой как основной знак; не делать везде одинаковый яркий неон.
- Материальность: **Matte Black/Graphite**, электролайм как акцент, спокойные белые заголовки; микро-свечения только для фокуса и редких branded элементов. Вторичная тема **Electric Blue** остаётся отдельной согласованной темой; не переносить lilac/olive/старые green cards в неё.

## 2. Фоновые текстуры / опциональные обои

Согласованная концепция выбора оформления **в настройках**; четыре направления визуальных обоев:
1. **Matte Black** — чистый тихий фон по умолчанию, без узоров.
2. **Carbon** — микро-диагональное переплетение или матовая карбоновая текстура, как мотив иконки №20.
3. **Neon Threads / Flow** — тонкие непрерывные ленты/нити, мягкие длинные кривые с большим радиусом, плавное затухание/прозрачность, без резких переходов и пересечений на тексте.
4. **Topographic** — редкие тонкие изолинии/волны в низком контрасте, как у иконок №05 и №11.

**Правила:** фон не конкурирует с карточками, навигацией и фотографиями; минимальная насыщенность и низкая непрозрачность; неон расположен преимущественно у краёв/в hero/splash, без анимации по умолчанию; reduced-motion и фолбэк на чистый фон; отсутствие мерцания; независимая проверка контрастности текста и UI в каждой комбинации темы и обоев. Для Matte Black приоритет лаймовые/графитовые нити, для Electric Blue — тёмно-синие/нейтральные (ярко-сиреневый и зелёная подложка не должны нарушать Electric Blue). Не вводить яркую полноэкранную карбоновую рябь или визуальный шум.

## 3. Где применять и как принимать

- **Логотип:** экран приветствия/авторизации, компактная шапка, профиль, маркетинговые иллюстрации; подлинная рыбка — часть брендинга, **не заменяет работающий знак навигации**.
- **Нижняя навигация остаётся:** `Лента / Комьюнити / + / Выезды / Чат`; обои не перекрывают фиксированное меню и safe area.
- **Семейство идентичности:** одинаковая типографика на ZAPRUDA, ZAPRUDA COMMUNITY и ZAPRUDA SPOT. Имя ZAPRUDA — главный бренд, подпись роли — вторична.
- **Финальная отрисовка для разработки:** изготовить чистые **SVG outlines** знака/рыбы/локапов (без непроверенных сторонних шрифтов), экспорт прозрачных PNG, favicon, apple-touch-icon, Android adaptive icon; проверить монохромный вариант и читаемость в 24, 32, 48, 64, 128, 512 px; обеспечить safe zone, контраст и размеры touch target.
- **Прототипы перед установкой:** лента, профиль, чат, STREET, SPOT + settings/theme/wallpaper picker; сравнить обе темы, 320/390/768/1440, реальный контент и пустые состояния. Только по отдельной визуальной приёмке заменить используемые UI assets в code PR.
- **Не копировать размытые генеративные картинки в приложение как production SVG**: презентационные листы являются образцами направления; финальные мастер-активы должны быть графически отстроены и валидированы.

## 4. Границы текущего решения

**Утверждена концепция айдентики.** Не утверждены точные глифы, kerning, масштаб рыбы, линии обоев, анимация, окончательные иконки для магазинов, итоговые скриншоты интерфейса и pixel-perfect acceptance. Их отработать как следующий этап. Вся существующая функциональность и 56 feature IDs/8 модулей/7 KING-титулов сохраняются. Никаких изменений main, production, тегов и релизной версии из-за этого решения.

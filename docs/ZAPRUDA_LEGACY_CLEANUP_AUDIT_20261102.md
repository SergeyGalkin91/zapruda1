- `src/routes/__root.tsx` содержит англоязычные 404 и Lovable error reporting; удалять интеграцию можно только после проверки всех импортов и runtime-зависимостей.

## Правила безопасной очистки
1. Проверить полный граф импортов и маршрутов (включая динамические импорты), перед физическим удалением файлов.
2. Проверить Supabase queries, RLS, платежи, приватность координат и CI для каждого кандидата.
3. Код удалять отдельным узким Draft PR, сначала Alpha preview и тесты; не переписывать историю Git.
4. Никаких автоматических удалений миграций, пользовательских таблиц, данных и legacy RPC без отдельного аудита.

## Итог текущего прохода
Подтверждённых **неиспользуемых файлов, существующих в текущей Alpha**, ещё недостаточно для безопасного физического удаления: полное сканирование репозитория не выполнено. Этот PR только документирует проверенную инвентаризацию и решения об архиве.

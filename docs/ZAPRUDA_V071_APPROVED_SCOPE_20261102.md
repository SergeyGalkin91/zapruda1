# ZAPRUDA COMMUNITY — v0.7.1 утверждённые задачи

Статус: **release planning / not implemented**. Дата фиксации: 2026-11-02. Основой остаётся `release/v0.7.0-alpha`; никаких автоматических merge в main или изменений production.

## MUST HAVE: СХОДКИ
- Отдельный раздел в Комьюнити для локального поиска рыболовных встреч.
- Объявления с фильтрацией страна → регион → город, например Россия → Нижегородская область → Нижний Новгород. Видимость строго в выбранном городе.
- Отклик на объявление; организатор принимает отклик → создаётся приватная СХОДКА с обсуждением точного места/времени.
- **Максимум три человека с организатором**, атомарная серверная проверка даже при одновременных откликах.
- Приватность точных спотов и закрытых переписок, RLS, реальные тестовые JWT.
- Дизайн утверждён ориентировочно: graphite / lime #D7FF35, крупный заголовок, выбор локации, «+ Создать объявление», «Мои сходки», карточки со счётчиком 1/3 и «Откликнуться». Адаптация под мобильный экран обязательна.
- Не путать с КЛУБАМИ: 500 ₽ / максимум 15 участников; не путать с платными услугами гидов.

## Порядок реализации
1. Согласовать фактическую схему и миграции на отдельном Supabase STAGING, не копируя персональные данные из production.
2. Серверный API/RLS/блокировка при одновременном принятии; тесты участников и доступа посторонних.
3. Реальные формы объявлений и откликов, маршрут СХОДКИ, фильтр города и закрытый чат.
4. Проверка мобильного UI, сборки, E2E и приватности; только затем решение о релизе.

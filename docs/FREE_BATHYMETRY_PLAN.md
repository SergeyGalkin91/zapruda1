# Бесплатные карты и глубины — ZAPRUDA

## Принцип
Используем только источники с проверенным правом на использование в коммерческом приложении, атрибуцией и соблюдением правил доступа. **Отсутствие данных не заменяем выдуманными глубинами.** Не копируем закрытые тайлы Garmin/Navionics/Dap Drift/прочих сервисов.

## Бесплатная подложка
- **OpenFreeMap** — https://openfreemap.org/ ; коммерческое использование заявлено как разрешённое, без API-ключа и платы за просмотры. Проверять актуальные https://openfreemap.org/tos/ . Публичная инфраструктура без SLA; возможно самостоятельное размещение.
- Исходная география — **OpenStreetMap** (ODbL), обязательно указание авторства.
- Публичные тайлы с tile.openstreetmap.org **не предназначены для неограниченных запросов**: https://operations.osmfoundation.org/policies/tiles/ . Для масштабирования использовать OpenFreeMap или собственный тайл-сервер.

## Водные объекты и глубины
- **HydroLAKES** https://www.hydrosheds.org/products/hydrolakes — CC BY 4.0, площадь, контуры, оценка средней глубины. Не содержит детальных изобат для всех российских рек.
- **GLOBathy** https://doi.org/10.6084/m9.figshare.c.5243309.v1 — модель озёрных глубин, не инструмент безопасной навигации. В каталоге Google Earth Engine лицензия *assumed CC0*, что не является достаточным подтверждением для автоматического коммерческого использования. До письменного или первичного подтверждения лицензии **не загружать и не распространять данные**.
- Пользовательские GPS+эхолот промеры с явным разрешением автора — основной путь к собственным изобатам в районе Нижнего Новгорода. GPS-треки без измерений глубины сами по себе глубин не дают.

## Требования к UI
1. Слои: «Карта», «Мои замеры глубин», затем «Открытые оценки глубин» лишь при проверенной лицензии и наличии данных.
2. Каждый замер должен иметь источник, координаты, значение глубины в метрах, дату и тип достоверности (замер/модель).
3. Запретить отображение недостоверных измерений как точных карт; обязательное предупреждение, что данные не для навигации.
4. Публикация координат точек — добровольная, приватность по умолчанию.
5. Не путать бровки и ямы по данным эхолота с усреднённой глубиной HydroLAKES.

## Технический план
- На тестовой ветке интегрировать MapLibre GL JS + OpenFreeMap (темный стиль) как альтернативу текущей карте, без платного ключа.
- Хранить замеры в Supabase с RLS, валидацией диапазонов, защитой от массового спама; сначала частные замеры и CSV-импорт.
- Добавить геослой точек замеров, затем интерполяцию изобат на **достаточной** плотности независимых точек и отрисовку с меткой качества.
- Ни один сервис с неизвестной коммерческой лицензией автоматически не подключать.

Источники проверены 2026-10-30: OpenFreeMap https://openfreemap.org/tos/ ; HydroLAKES https://www.hydrosheds.org/products/hydrolakes ; OSM tiles https://operations.osmfoundation.org/policies/tiles/ .

**Назначение:** дать владельцу короткий практический сценарий для реального телефона и компьютера. Это НЕ подтверждённый результат тестирования и НЕ разрешение публикации.

- [ ] Действующий **отдельный STAGING URL**, точные deploy ID и commit SHA; приложение открывается по HTTPS без ошибок сертификата. Домен `zaprudacommunity.ru` — будущий production canonical, **не использовать его вместо STAGING**, пока не выполнена приёмка.

- [ ] На опубликованной сборке пройдены HTTP/SSR проверки, базовый login/logout с реальным подтверждённым TEST-пользователем, мобильное отображение, пустые состояния.
- [ ] P0 GPS/EXIF: тестировать лишь безопасные сценарии на изолированных тестовых данных; не публиковать реальные точки до закрытия security gate.
